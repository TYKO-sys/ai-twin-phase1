Step 1: Create Your Telegram Bot

Your AI twin lives in a Telegram chat. First, you need to create a bot.

  1. Open Telegram and search for @BotFather
  2. Send the message: /newbot
  3. Give it a name (anything you want, e.g., "AI Twin")
  4. Give it a username ending in "bot" (e.g., "yourname_twin_bot")
  5. BotFather will give you a token — copy it
Open @BotFather

Looks like: 123456789:AAH-xxxxx...

Step 2: Get Your Telegram ID

This locks the bot so only YOU can talk to it.

  1. Open Telegram and search for @userinfobot
  2. Send any message (or tap Start)
  3. It replies with your user info — find the Id number
  4. Copy that number
Open @userinfobot

Step 3: Choose Your AI Brain

Your twin needs an AI to think. You can use one or both.

Option A: OpenRouter (Recommended)

Access to 300+ AI models. More reliable than Gemini. $5 free credit.

  1. Go to openrouter.ai/keys
  2. Sign in with Google or GitHub
  3. Click "Create Key"
  4. Copy the key (starts with sk-or-v1-)
Get OpenRouter Key

Option B: DeepSeek (Recommended)

Cheap, high quality, generous free tier. Very reliable.

  1. Go to chat.deepseek.com
  2. Sign up
  3. Go to Settings → API keys
  4. Create a key and copy it
Get DeepSeek Key

Option C: Z.ai (Free)

GLM models, free tier. Good as a backup.

  1. Go to chat.z.ai
  2. Sign up
  3. Go to Settings → API key
  4. Copy the key
Get Z.ai Key

Option D: Gemini (Fallback)

Google's free AI. 250 requests/day. Gets rate-limited during peak hours.

  1. Go to aistudio.google.com/apikey
  2. Sign in with Google
  3. Click "Create API Key"
  4. Copy the key (starts with AIza)
Get Gemini Key

You need at least one. The more you add, the more reliable your twin is — it rotates between them automatically.
